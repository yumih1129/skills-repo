 # 主题新闻简报检索 使用手册

## 技能概述

**技能名称**：主题新闻简报检索

**标识**：`news-briefing-search`

**版本**：1.3.0

**功能**：根据指定时间范围或按最新顺序检索特定主题新闻，并将结果整理为结构化新闻简报，支持多语言新闻检索与摘要。

---

## 快速开始

### 基本用法

直接描述你的任务需求即可触发该技能，例如：

```text
搜索人工智能最近一周的新闻
查找比亚迪最新消息
搜一下量子计算近期动态
用英文搜索特斯拉新闻
```

---

## 功能特性

### 支持的能力

| 能力 | 说明 |
|------|------|
| 多语言新闻搜索 | 支持中文、英文、日文、韩文新闻检索与翻译 |
| 时间范围控制 | 支持近日(3天)、近一周(7天)、近期(30天)、近N天/周/月/年及特定月份/季度 |
| 智能关键词处理 | 自动识别宽泛关键词并扩展搜索策略 |
| 质量过滤 | 基于字符数、具体信息量、引述等指标评分过滤 |
| 去重与排序 | 按标题重复度去重，分类内按时间降序排列 |
| 自动分类 | 将新闻归入预定义分类体系 |
| 多工具适配 | 自动发现并选择当前环境中最合适的WebSearch工具 |

---

## 使用方式

### 适合的输入

- 搜索特定主题的最新新闻（如"人工智能新闻"）
- 查找某事件在指定时间范围内的报道（如"过去一个月的新能源汽车新闻"）
- 了解某话题的近期动态和进展
- 获取国际新闻的英文原文报道
- 整理特定行业的新闻简报

### 执行特点

- 用户未指定时间范围时，默认使用"近期"（最近30天）
- 单次搜索时间范围不超过30天，超过时分批搜索后合并
- 多语言搜索时，未指定时间范围默认缩短为7天
- 自动进行质量过滤，去除广告和内容空洞的条目

---

## 输出结果

- 结构化新闻简报，包含标题、来源、发布时间、摘要、正文、链接
- 按分类组织，每类内按时间降序排列
- 多语言新闻带有语言标签（[EN]等）和来源标注
- 每条新闻附带质量评分依据

---

## 使用示例

### 示例1

**输入**：

```text
人工智能最近一周有什么新闻
```

**输出**：

结构化新闻列表，按发布时间降序排列，包含人工智能领域的最新动态报道。

### 示例2

**输入**：

```text
用英文搜索量子计算国际新闻
```

**输出**：

带有[EN]标签的英文新闻简报，包含Reuters、BBC等权威国际媒体来源，保留英文标题和中文翻译摘要。

### 示例3

**输入**：

```text
帮我查一下中国市场监管的最新动态
```

**输出**：

中国市场监管相关的新闻简报，自动归入相应分类，含发布时间、来源、摘要和正文。

---

## 注意事项

1. 多语言搜索时，同一事件有多语言来源时按"用户指定来源 > 权威国际媒体 > 其他来源"顺序保留
2. 宽泛关键词（如"中国"、"新闻"）可能触发扩展搜索策略，需补充限定词以获得更精准结果
3. 内容空洞（正文不足100字符且无实质信息）的条目会被过滤，不进入最终简报
4. 当没有任何可用WebSearch工具时，会明确告知用户无法完成实时搜索

---

## 适用场景

- 了解某个话题的最新动态和行业趋势
- 获取特定事件的新闻报道和进展追踪
- 整理特定领域的近期新闻简报
- 搜索和翻译国际新闻（英文为主）
- 获取政策、行业、地区相关的定期新闻汇总
