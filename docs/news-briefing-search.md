# 主题新闻简报检索 使用手册

## 技能概述

**技能名称**：主题新闻简报检索

**标识**：`news-briefing-search`

**版本**：1.4.0

**功能**：根据指定时间范围或按最新顺序检索特定主题的新闻，并将结果整理为结构化新闻简报，支持多语言新闻检索与摘要。

---

## 快速开始

### 基本用法

直接描述你的任务需求即可触发该技能，例如：

```text
搜索人工智能最近一周的新闻
```

```text
帮我查一下新能源车最近有什么最新消息
```

```text
搜索一下DeepSeek的最新进展
```

---

## 功能特性

### 支持的能力

| 能力 | 说明 |
|------|------|
| 主题新闻检索 | 根据关键词和时间范围搜索新闻 |
| 多时间范围支持 | 支持近日（3天）、近一周（7天）、近期（30天）及自定义时间范围 |
| 多语言新闻搜索 | 支持中文、英文、日文、韩文新闻检索 |
| 并行搜索 | 单次结果不足5条时自动并行搜索 |
| 质量过滤 | 评分制过滤广告/软文/内容空洞条目 |
| 智能去重 | 按标题完全相同或字符重叠率≥80%去重 |
| 文件导出 | 支持导出为 Markdown 或 JSON 格式 |
| 宽泛关键词处理 | 单字或常见词自动扩大时间范围重试 |

---

## 使用方式

### 适合的输入

- 搜索特定主题的最新消息（如"人工智能最新新闻"）
- 查找某事件在特定时间段内的报道（如"过去一个月的新能源政策"）
- 了解某话题的多语言国际资讯（如"用英文搜索特斯拉的新闻"）
- 整理特定领域的新闻列表并导出

### 执行特点

- 默认时间范围为"近期"（30天内）
- 单次搜索时间范围不超过30天；超过时自动分批搜索后合并
- 自动选择可用的高质量搜索工具
- 多语言搜索默认缩短为7天内（用户未指定时）
- 搜索结果须通过质量评分（≥5分）才保留

---

## 输出结果

- 结构化新闻简报，包含标题、来源、发布时间、摘要、正文、链接
- 多语言结果标注 `[EN]`、`[JA]`、`[KO]` 等语言标签
- 英文来源标记为 `来源: Reuters`、`来源: BBC` 等格式
- 支持 Markdown 或 JSON 格式导出到指定路径

## 注意事项

1. 单次搜索时间范围不超过30天；超过30天时分批搜索后合并去重
2. 多语言新闻（英文/日文/韩文）默认只搜索最近7天，用户未指定时间范围时自动缩短
3. 宽泛关键词（如"中国"、"市场"）会自动扩大时间范围重试，仍不足5条时提示用户补充限定词
4. 无可用搜索工具时明确告知用户，不伪造结果
5. 过滤规则：广告/软文（含"限时优惠"等）、正文不足100字符且无实质内容者不保留
