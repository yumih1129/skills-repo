# 主题新闻简报检索 使用手册

## 技能概述

**技能名称**：主题新闻简报检索

**标识**：`news-briefing-search`

**版本**：1.7.0

**功能**：根据指定时间输入（时间点、时间段或相对时间）或按最新顺序检索特定主题的新闻，并将结果整理为结构化新闻简报，支持多语言新闻检索与摘要。

---

## 快速开始

### 基本用法

直接描述主题和时间即可触发，例如：

```text
搜索人工智能最近一周的新闻
```

```text
查一下2026年5月关于新能源汽车的报道，导出为 Markdown
```

```text
用英文搜索国际AI监管新闻，保存到 outputs/news/
```

---

## 功能特性

### 支持的能力

| 能力 | 说明 |
|------|------|
| 灵活时间解析 | 支持时间点（如 `昨日`、`2026-05-25 14:00`）、时间段（如 `本周`、`2026-05-01 至 2026-05-07`）和相对时间（如 `最近一周`、`近三个月`），自动换算检索时间窗 |
| 智能工具选择 | 自动发现当前环境中可用的 WebSearch 工具，按评分（支持自然语言 query、时间过滤、结构化返回等 7 项）选择最优工具，支持并行搜索和工具降级 |
| 质量过滤与去重 | 过滤广告、内容空洞条目，按正文实质内容评分（字符数、具体数字、名称、引述等），并按标题重叠率、语义重复等 4 层去重 |
| 安全降级过滤 | 对政治/军事/灾害/治安四类敏感题材自动降级，宽泛主题中敏感题材超 50% 时只保留非敏感结果 |
| 多语言新闻检索 | 支持中/英/日/韩四种语言，自动构建多语言 query、保留来源权威顺序、标记语言标签（如 `[EN]`） |
| 结构化输出与导出 | 输出完整简报（时间输入、检索时间窗、主题关键词、结果数量、6 分类新闻条目），支持 Markdown 和 JSON 两种导出格式，按用户指定路径或默认命名规则写文件 |

---

## 使用方式

### 适合的输入

- 主题关键词 + 时间表达，如"人工智能最近一周"
- 时间点查询，如"昨日热点新闻"
- 时间段查询，如"2026年5月的新能源汽车新闻"
- 多语言搜索，如"用英文搜索国际AI监管新闻"
- 指定导出格式和路径，如"导出为 Markdown 放到 outputs/目录"

### 执行特点

- 先解析时间输入并换算为检索时间窗（左闭右开），再构建 query、发现工具、执行检索
- 时间点自动窗口化（日级 → 00:00~次日00:00，小时级 → 该小时起点~下一小时起点），保留用户原始时间输入不变
- 默认返回 5-10 条结果，用户可指定 1-20 条；超过 10 条自动启用并行搜索
- 结果按 6 大分类（国内要闻、国际动态、财经证券、科技体育、社会民生、行业观察）组织，分类间按数量降序，分类内按发布时间降序
- 导出文件命名遵循固定规则：`news-briefing-{topic-key}-{time-key}.{ext}`，时间键按语义类型折叠为 `recent-Nd`、`YYYYMMDD` 或 `YYYYMMDD-YYYYMMDD`

---

## 输出结果

### 对话内输出

直接返回结构化新闻简报，包含：

- 头部信息：时间输入、检索时间窗、主题关键词、结果数量
- 分类统计：各类别条数
- 新闻条目：每条含标题、来源、发布时间、摘要、正文、链接（必填 6 字段），按分类和发布时间组织

### 导出文件

- **Markdown 导出**：输出完整简报 Markdown 文件，使用 `##` 分类标题、`### 序号.` 新闻标题格式
- **JSON 导出**：输出结构化 JSON，含时间输入、检索时间窗、主题关键词、结果数量、内容分类对象和新闻数组
- **文件命名**：按 `news-briefing-{topic-key}-{time-key}.{ext}` 规则自动生成；用户指定文件路径时优先使用用户路径

## 使用示例

### 示例 1：主流程 — 相对时间检索

**输入**：

```text
搜索人工智能最近一周的新闻
```

技能解析"最近一周"为 7 天 → 构建 query `人工智能 最近一周 新闻` → 选择最优 WebSearch 工具 → 过滤去重 → 分类整理 → 输出 5-10 条简报。

### 示例 2：边界 — 不适用场景误触发

**输入**：

```text
搜索茅台股价
```

技能识别为金融数据需求，属于不适用场景，不误用新闻简报流程，建议使用金融数据工具。

### 示例 3：输出 — 指定导出路径

**输入**：

```text
把热点新闻近30天的结果保存到 outputs/news/
```

技能检索 30 天内热点新闻 → 生成文件名 `news-briefing-热点新闻-recent-30d.md` → 写入 `outputs/news/` 目录，回报相对路径。

## 注意事项

1. 本技能只检索新闻；财报数据、学术论文、历史事件详情、实时行情等均属于不适用场景，应转交对应专门工具。
2. 搜索宽泛关键词（单字或极常见词）时，若有效结果不足 5 条且时间窗小于 30 天，会自动扩大时间窗重试一次；仍不足则提示补充限定词。
3. 工具全部限流或不可用时，明确报告失败原因，不伪造链接或生成模拟结果。
4. 用户指定的文件路径与导出格式扩展名冲突时，优先使用用户路径写入，并在回复中说明格式不一致的风险。
5. 安全降级过滤是强制规则：热点类宽泛主题中敏感题材超 50% 时自动缩减为非敏感结果；触发 `new_sensitive` 拦截时停止扩大搜索。
6. 文件名总长度控制在 60 字符以内（不含扩展名），时间键按语义类型折叠为 `recent-Nd`、单日键或区间键，不把原始 query 直接写入文件名。

## 适用场景

- 了解某个话题的最新动态
- 获取某事件在指定时间内的新闻报道
- 整理特定领域的近期新闻
- 搜索国外新闻、外媒报道或国际资讯（中/英/日/韩）
- 导出结构化新闻简报为 Markdown 或 JSON 文件
