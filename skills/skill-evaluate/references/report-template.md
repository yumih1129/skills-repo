# SKILL 评估报告模板

按本模板输出时，先完成证据采集、评分、基线判定、问题分级和最终判定，再一次性生成报告。报告可以把最终摘要放在顶部，但该摘要必须由最终判定回填，不得来自基线判定。

- 模板版本：`skill-evaluate-report/v1`
- 量表版本：`skill-evaluate-rubric/v1`
- 适用范围：仅用于用户要求完整评审、正式报告、交付评审或评分表时；用户只要求先看结论、快速简报或审阅判断时，输出结论版，不套用本模板。
- 渲染要求：完整报告只能使用本模板的固定章节顺序和固定标题模式，不得改写为旧版“阶段流水账”或自定义总结结构。
- 标题规则：将模板中的 `{技能名称}` 替换为被评估对象的 `name`；若 `name` 缺失、为空、非字符串或不符合 G1 名称检查点，使用被评估目录名，并在摘要或证据范围中注明来源。
- 文件命名：完整报告默认保存为 `{slug}.md`，只使用 `slug` 本身，不追加 `-评估报告`、标题后缀或其他说明性后缀；`slug` 取被评估对象的 `_meta.json` 中的 `slug`，缺失或不可读时使用被评估目录名；如需保留历史快照，另存为明确标识的新文件，不在旧文件末尾追加。
- 复评稳定性：同一对象、同一模式、同一证据快照、同一量表版本下，报告的章节顺序、表格行顺序、检查点名称、分值、问题清单和最终等级必须完全一致；除证据项、文件时间戳和 hash 外，不得因改写表达而改动评分点或结论。
- 输出原则：先算完再输出，禁止边评边写最终报告。
- 报告自检属于生成前内部校验，不作为报告正文输出。
