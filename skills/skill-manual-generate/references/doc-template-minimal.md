# SKILL 使用手册模板（极简版）

用于生成目标 SKILL 的简洁使用手册。请基于目标 `SKILL.md` 与 `_meta.json` 的真实内容填写，不得编造能力。

````markdown
# {技能名称} 使用手册

## 概述

**技能**：{技能名称}

**标识**：`{slug}`

**版本**：{version}

**功能**：{一句话功能说明}

## 如何使用

直接描述你的任务需求即可触发，例如：

```text
{示例请求1}
{示例请求2}
{示例请求3}
```

## 能力

- {能力1}
- {能力2}
- {能力3}

## 输出

- {输出结果1}
- {输出结果2}
- {输出结果3}

## 示例

### 示例1
```text
{示例输入1}
```

### 示例2
```text
{示例输入2}
```

### 示例3
```text
{示例输入3}
```

## 注意事项

- {注意事项1}
- {注意事项2}
- {注意事项3}

## 相关文件

- 技能定义：`{project_relative_skill_dir}/SKILL.md`
- 元数据：`{project_relative_skill_dir}/_meta.json`
````

使用规则：

- 仅保留最核心信息，避免展开过多章节。
- 当目标 SKILL 本身较简单、或用户明确要求“极简 / 简约 / 轻量 / 最短”时优先使用。
- 仅在主流程选择极简模板时使用；若无法明确归入极简模板，则改用标准模板。
- 章节顺序固定，不新增额外章节，不混用多个近义标题。
- 示例按固定顺序填写，最多 3 组：
  1. 主流程示例。
  2. 边界、限制、失败或回退示例。
  3. 输出、交付物或结果示例。
- 若合计不足 3 组，只写可证实的全部示例，不补造。
