## 使用规则

- 标题默认使用“{技能名称} 使用手册”。
- 文件名不取标题，固定取目标 `_meta.json` 中的 `slug`。
- 章节顺序保持不变；章节标题只允许做一次性、同义且必要的微调，不能在同一份文档中混用多个近义标题。
- 若目标 SKILL 更强调交付物、执行流程或输出产物，可将“输出结果”替换为更贴切且单一的标题。
- 示例按固定顺序填写，最多 3 组：
  1. 主流程示例。
  2. 边界、限制、失败或回退示例。
  3. 输出、交付物或结果示例。
- 若合计不足 3 组，只写可证实的全部示例，不补造。
- 若用户提供 `reference_doc_path`，只借鉴其结构与语气，不借鉴目标能力之外的内容。
- 当前模板仅在主流程选择标准模板时使用。
- 最终文稿必须是标准 Markdown，可直接写入 `{output_dir}/{slug}.md`。
