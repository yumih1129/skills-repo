# 主题规范

本文件是当前技能的自包含主题规范。它已经把历史校准信息内化到技能目录内部，执行本技能时不再要求读取任何技能目录外资源。

## 权威顺序

主题相关规则按以下顺序生效：

1. `references/theme-spec.md`：定义每个主题的组件职责、结构语法和禁止漂移项。
2. `assets/theme-presets.js`：定义脚本渲染用的样式 token。
3. `references/render-contract.md`：定义组件如何进入内部结构。
4. `SKILL.md`：定义何时触发、何时交付、如何复评。

若 `theme-presets.js` 与本文件冲突，以本文件为准修正。

## 统一原则

1. 同一主题的组件语法固定，不允许混用其他主题组件。
2. 同一主题下，内容可以变，组件长相不能变。
3. 标题、导语、提示块、二级标题、三级标题、引用、表格、题注和代码块是重点对齐对象。
4. 本文件中已定义的组件，输出时必须优先沿用；不能用“通用模板感”替代。
5. 本文件中未定义的组件，新增时只能使用与该主题一致的低风险写法。

## 视觉质量底线

无论使用哪个主题，最终版式都必须同时满足：

- `整齐`：同层级组件的边距、对齐和视觉重量稳定，不出现一会儿像论文、一会儿像营销海报的断层。
- `精美`：强调色、边框、圆角和底色有克制感，不能为了“好看”堆叠过多装饰。
- `清爽`：留白足够但不过度松散，正文始终是页面主角。
- `可读`：标题有信息层级，导语有引入作用，正文密度适合手机端连续阅读。
- `克制`：高强调块只服务重点信息，不得连续堆叠多个 `callout`、引用或装饰性标题造成视觉噪声。

## 组件词汇表

- `eyebrow`：标题前的主题标签段落
- `lead`：标题后的主导语
- `callout`：导语后的提示块或概览块
- `meta`：标题后、摘要前的前置信息行
- `keywords`：摘要后的关键词行
- `h2`：主章节标题
- `h3`：局部小标题
- `quote`：引用块
- `table-label`：表格题签
- `table-note`：表格说明或图注式说明
- `code-block`：代码块

## 主题画像与组件锚点

### `wechat-native-template`

组件锚点：

- 无 `eyebrow`
- `h1` 为居中轻边框圆角标题卡
- `lead` 为浅青底、左强调线的单段导语
- `h2` 为胶囊式浅底标题
- `quote` 为浅青底轻卡片
- 表格为完整边框结构，首列浅底加粗
- 代码块为浅底细边框

禁止漂移：

- 不得把 `h2` 改成纯文本下划线风
- 不得给 `h3` 增加胶囊或块状背景

### `academic-paper-template`

定位：

- 这是论文主题的规范键名。
- `wechat-default-template` 仅作为兼容旧调用的别名保留。
- 它不是未指定主题时的默认样式；未指定主题时，默认仍是 `wechat-native-template`。

组件锚点：

- 无 `eyebrow`
- `h1` 为居中论文式标题
- 标题后是论文式前置信息：作者、单位、日期
- `lead` 对应“摘要”标题 + 摘要正文
- 摘要后有 `keywords` 行
- `h2` 为居中纯文本学术标题
- `quote` 仅保留左细线，不做卡片
- 表格为论文式顶线/表头下横线/底线结构
- 代码块为浅底细边框，衬线字体

禁止漂移：

- 不得加入营销卡片、胶囊标题或品牌色强调块
- 不得把论文式前置信息压缩成普通导语段落

### `apple-style-template`

组件锚点：

- `eyebrow` 居中、灰色、全大写
- `h1` 居中、系统文档感
- `lead` 居中窄宽段落
- `callout` 为近白浅灰卡片，圆角更大
- `h2` 为细底线分节
- `h3` 为全大写小标题
- 表格题签字号略大于其他主题

禁止漂移：

- 不得改成左强调线章节标题
- 不得把 `callout` 做成高饱和强调卡

### `claude-code-template`

组件锚点：

- `eyebrow` 左对齐，暖棕灰
- `lead` 为暖灰正文导语
- `callout` 为暖米白卡片 + 棕褐左强调线
- `h2` 为底线分节
- `h3` 为左细线小标题
- `quote` 为暖底轻卡片
- `code-block` 为深棕黑底、浅米字

禁止漂移：

- 不得使用冷青、亮蓝或紫色强调
- 不得把代码块换成浅底工程风

### `codex-template`

组件锚点：

- `callout` 为浅青底说明块
- `h2` 为左强调线章节标题
- `h3` 为窄左线小标题，不带背景
- `quote` 为浅青底卡片
- 表格首列浅青底，其他列白底
- `code-block` 为深青黑底

禁止漂移：

- 不得加入亮色强调线或高饱和块

### `obsidian-template`

组件锚点：

- `eyebrow` 左对齐，灰紫
- `callout` 为浅紫底卡片
- `h2` 为左强调线标题
- `h3` 为浅紫底小块

禁止漂移：

## 组件一致性检查清单

生成前或复评时，至少检查：

- 主题是否已正确归一化到内置主题名
- 当前主题无法映射的组件是否已整篇回退到微信原生主题，而不是回退到基础样式或自拟样式
- `eyebrow` 是否只出现在本主题支持的场景中
- `callout` 是否匹配该主题的边框、背景、圆角和标签写法
- `h2` 是左线、下边线、胶囊还是纯文本，是否与本文件一致
- `h3` 是纯文本、胶囊、小块还是左细线，是否与本文件一致
- `quote` 的背景、边线和圆角是否一致
- 表格题签与表格说明是否符合本文件约束
- 代码块底色、边框和字体是否一致

任一项不一致，都应视为主题漂移，必须修正。
