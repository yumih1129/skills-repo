# Skill: 主题新闻简报检索 (news-briefing-search)

## 本地资源与权威顺序

1. `SKILL.md` frontmatter：只定义技能名称与触发描述。
2. `SKILL.md` 正文：只定义触发边界、工具规则、执行流程、输出结构和异常处理；正文与其他本地文件冲突时，以正文为准。
3. `_meta.json`：只提供注册与展示元数据，不补充、不覆盖、不改写执行规则。

## 何时使用

当用户需要根据指定时间范围或按最新顺序检索特定主题的新闻，并将结果整理为结构化新闻简报时使用。

### 适用场景
- 了解某个话题的最新动态
- 获取某事件的新闻报道
- 整理特定领域的近期新闻
- **多语言新闻搜索**：搜索国外新闻（英文为主）、翻译外媒报道、整理国际资讯

### 不适用场景
- 搜索特定公司的财报数据（应使用金融数据工具）
- 搜索学术论文或专利（应使用学术搜索工具）
- 搜索历史事件详情（应使用百科/知识库工具）
- 需要实时行情、价格、交易数据（应使用金融数据API）

## 工具原则

本技能不绑定任何固定的 WebSearch 实现名。执行时应先发现当前环境中可用的搜索工具，再根据能力、可用性和结果质量选择调用对象。

### 可用 WebSearch 工具的定义
满足下列条件之一即可视为可用 WebSearch 工具：
- 能接收主题关键词、时间范围或站点限定等搜索参数。
- 能返回标题、来源、发布时间、摘要/片段、链接中的至少 4 项。
- 能按新闻或网页结果进行检索，并支持基于相关性或时间排序。

### 工具选择原则
按以下顺序选择工具；命中后继续比较下一项，直到分出唯一结果：
1. 支持自然语言 query、时间过滤、结构化返回、链接可追溯四项能力的工具优先。
2. 在返回结果中，能稳定提供标题、来源、发布时间、摘要/片段、链接五字段的工具优先。
3. 支持新闻结果检索或时间排序的工具优先。
4. 仍并列时，选择当前环境中第一个可调用的工具。

并行或切换规则：
- 单工具结果不足 5 条时，进入并行搜索。
- 单工具返回质量过滤后有效结果不足 5 条时，进入并行搜索。
- 用户要求“最新”时，进入并行搜索。
- 关键词命中“宽泛关键词处理”规则时，进入并行搜索。
- 当前环境没有任何可用 WebSearch 工具时，明确告知用户无法完成实时搜索，不伪造结果。

### 触发词
**核心**：搜索XX新闻、查找XX最新消息、搜一下XX、XX最近有什么新闻、整理成新闻列表、生成新闻摘要、XX最近动态、过去N天/周/月/年的XX新闻

**扩展**：获取XX资讯、XX今日热点、追踪XX动态、XX行业新闻、XX要闻、播报XX新闻、XX事件进展

**口语化**：XX有啥新消息、帮我看看XX的最新情况、查一下XX最近的消息、最近XX怎么样、有XX的最新动态吗、推荐些XX的新闻给我

**地区/行业**：XX地区有什么新闻、XX行业最近动态、看看XX公司/产品的消息、XX政策最新内容

**多语言新闻**：用英文搜索XX、搜一下国外XX新闻、找些XX的英文报道、XX international news、XX最新进展（国际）、翻译XX外媒报道

## 时间要素

| 表达 | 含义 |
|------|------|
| 近日 | 3天内 |
| 最近一周/近一周 | 7天内 |
| 近期/最近 | 30天内 |
| 过去N天/周/月/年 | 按指定时间 |
| 上个月 | 上月1日至月末 |
| 本月 | 本月1日至当日 |
| 本季度 | 当前季度首日至季度末 |
| 近三个月 | 90天内 |
| 本周 | 本周一至当日 |

**规则**：单次搜索时间范围不超过 30 天；超过 30 天时分批搜索；用户未指定时默认“近期”（30天）。

执行规则：
- 单次搜索时间范围不超过 30 天。
- 用户指定范围超过 30 天时，按时间顺序拆成多个不超过 30 天的批次分别搜索，最后合并、去重、排序。
- 用户未指定时间范围时，使用“近期”，即最近 30 天。
- 多语言搜索命中“多语言新闻处理”时，且用户未明确给出时间范围，默认缩短为最近 7 天。

## 多语言新闻处理

### 适用情况
- 用户明确要求英文/外文新闻
- 搜索国外事件、国际组织动态
- 搜索国际企业或人物的英文报道

### 处理流程
1. **识别语言需求**：按以下顺序判断，命中后停止：
   - 用户明确指定语言。
   - 用户输入包含语言关键词，如“英文”“日文”“韩文”“international”。
   - 用户明确要求国外新闻、外媒报道或国际资讯。
   - 以上都不满足时，使用默认中文。
2. **构建多语言 Query**：在基础 query 后追加语言限定词；只有用户明确要求外媒、国外新闻或国际资讯时，才追加站点限定词（如 `site:reuters.com OR site:bbc.com`）。
3. **质量判断**：
   - 英文标题+英文正文 → 直接使用
   - 英文标题+中文正文 → 保留英文标题 + 中文正文
   - 标题含中文关键词 + 正文为英文 → 提取摘要并翻译关键信息后保留
4. **输出格式**：
   - 英文来源标记：`来源: Reuters`、`来源: BBC`
   - 添加语言标签：`[EN]` 标注于标题前

### 多语言输出模板
```markdown
### [EN] 1. News Title in English
- **来源: Reuters** [EN]
- **发布时间**：YYYY-MM-DD
- **摘要**：（英文摘要翻译或中文提炼）
- **正文**：...
- **链接**：https://...
```

### 支持语言
| 语言 | 代码 | 说明 |
|------|------|------|
| 中文 | ZH | 默认语言 |
| 英文 | EN | 国际新闻、英文报道 |
| 日文 | JA | 日本相关新闻 |
| 韩文 | KO | 韩国相关新闻 |

### 注意事项
- 多语言搜索时，若用户未明确给出时间范围，默认缩短至 7 天内。
- 同一事件有多语言来源时，按以下顺序保留：用户指定来源 > 权威国际媒体 > 其他来源；同层内保留发布时间最新者。

## 执行流程

### 1. 解析关键词
从用户输入中提取主题关键词和时间范围；若用户未指定时间范围，默认"近期"（30天）。

同时提取以下导出相关信息：
- 导出格式：`Markdown` / `JSON`
- 目标路径：用户给出的文件路径或目录路径
- 是否要求写文件：命中“导出”“保存”“写入”“输出到文件”“放到某目录”等意图时为是

导出意图判断按以下顺序执行，命中后停止：
1. 用户明确说“导出为 Markdown / JSON”
2. 用户明确说“保存到”“写到”“输出到文件”“放到目录”
3. 用户给出明确的文件路径或目录路径，并要求产出文件
4. 以上都不满足时，视为仅在对话中返回结果，不写文件

**宽泛关键词处理**：
- 单字或极常见词（如"中国"、"新闻"、"市场"）判定为宽泛关键词
- 处理策略按以下顺序执行：
  1. 先按当前时间范围搜索。
  2. 若结果不足 5 条或质量低于“标题关键词重叠率 < 50%”，且当前时间范围小于 30 天，则扩大到最多 30 天后重试一次。
  3. 若重试后仍不足 5 条，或当前时间范围已经是 30 天，则提示用户补充限定词。

### 2. 构建Query
按以下顺序构建 query，并把结果交给当前可用的 WebSearch 工具：
1. 主题关键词
2. 时间表达
3. 固定词“新闻”
4. 语言限定词（仅在命中“多语言新闻处理”时追加）
5. 来源或站点限定词（仅在用户指定来源，或命中多语言外媒场景时追加）

基础示例：`人工智能 最近一周 新闻`

### 3. 发现并调用搜索工具
1. 检查当前环境中是否存在可用的 WebSearch 工具。
2. 按“工具选择原则”筛选最合适的工具。
3. 用统一 query 发起搜索；若工具支持时间过滤、站点限定或排序参数，则同步传入。
4. 记录本次所用工具名、搜索参数和返回批次，便于后续去重、复核和来源标注。

### 4. 质量过滤
保留标题含关键词且正文有实质内容的条目。过滤特征：
- 广告/软文：含"限时优惠""扫码领取""点击查看"等营销话术
- 内容空洞：正文不足100字符且无实质信息量

**正文实质内容判断（评分制）**：
| 评估项 | 得分 | 说明 |
|--------|------|------|
| 字符数≥100 | +4分 | 长度达标 |
| 字符数50-99 | +2分 | 长度基本达标 |
| 字符数<50 | +0分 | 长度不足 |
| 含具体数字（日期/百分比/金额等）≥1处 | +2分 | - |
| 含具体名称（人名/机构名/地名/产品名）≥2个 | +2分 | - |
| 含引述（原话引用、据XX报道等）≥1处 | +1分 | - |
| 含具体动作或事件（动词+结果）≥1组 | +1分 | - |

**通过标准**：总分≥5分

**快速判断**：字符数≥100直接通过；字符数<50直接不通过；字符数50-99时按上表评分

### 5. 去重检查
- 按以下顺序去重，命中后停止：
  1. **标题完全相同但来源不同**（如转载）：保留更新时间最新的。
  2. **字符重叠率≥80%**：保留发布时间最新者。

**简化语义去重**：当无法通过字符重叠率判断时，采用以下简化规则：
- 标题主语+宾语相同，动词近义（如"发布" vs "推出"）→ 语义重复，保留更新时间最新。

### 6. 验证与输出
1. 验证6字段完整：标题、来源、发布时间、摘要、正文、链接
2. 自动分类归入“分类体系”中的预定义分类。
3. 分类判断按以下顺序执行：标题关键词匹配 > 正文核心语义 > 来源媒体类型。
4. 若同一条新闻同时命中多个分类，按“分类体系”表格中的分类顺序取第一个命中的分类。
5. 排序输出：先按分类内发布时间降序；发布时间相同时按来源字母序；分类之间按新闻数量降序。

### 7. 导出路径解析与写文件

仅当 Step 1 判定为“要求写文件”时执行本步骤；否则跳过。

#### 导出格式规则

按以下顺序确定导出格式，命中后停止：
1. 用户明确指定 `Markdown` → 导出 `.md`
2. 用户明确指定 `JSON` → 导出 `.json`
3. 用户只要求“保存/导出”但未指定格式 → 默认导出 `.md`

#### 目标路径解析规则

按以下顺序解析目标路径，命中后停止：
1. 用户明确给出完整文件路径 → 直接写入该文件路径
2. 用户明确给出目录路径 → 必须写入该目录，不得回退到默认目录
3. 用户未给路径 → 写入当前工作目录

路径规则：
- 以下任一情况视为“文件路径”：
  - 用户明确说“文件名/保存为/写入到某个 `.md` 或 `.json` 文件”
  - 路径最后一段包含扩展名 `.md` 或 `.json`
- 以下任一情况视为“目录路径”：
  - 用户明确说“目录/文件夹/路径下”
  - 路径以 `/` 结尾
  - 路径最后一段不含扩展名，且用户语义明确要求“放到某个目录”
- 用户给出相对路径时，相对当前工作目录解析。
- 用户给出目录路径时，文件名固定按“默认文件名规则”生成。
- 用户给出文件路径时，不改文件名，只按指定扩展名写入；若未带扩展名，则按导出格式补全扩展名。
- 用户给出目录路径且目录不存在时，若当前环境允许创建目录，则创建后写入；若不允许创建，则明确告知路径不可写，不得静默回退到默认目录。
- 用户给出文件路径但父目录不存在时，按上一条处理。
- 当“文件路径”与“目录路径”两种判定同时可能成立时，以用户显式措辞优先；若用户未显式说明，则以是否带 `.md` / `.json` 扩展名作为唯一判定依据。

#### 默认文件名规则

默认文件名固定为：

`news-briefing-{topic-slug}-{start-date}-to-{end-date}.{ext}`

生成规则：
- `topic-slug`：将主题关键词转为小写 kebab-case；中文主题无法安全转写时，保留原中文并把空格替换为 `-`
- `start-date` / `end-date`：使用 `YYYY-MM-DD`
- `ext`：由导出格式决定，`md` 或 `json`

示例：
- 主题“人工智能”、时间范围 `2026-05-01` 至 `2026-05-07`、Markdown 导出
- 文件名：`news-briefing-人工智能-2026-05-01-to-2026-05-07.md`

#### 写文件门禁

- 用户指定目录时，最终写入路径必须落在该目录下。
- 用户指定文件路径时，最终写入路径必须与该文件路径一致。
- 任何写文件失败都必须显式报错，不得改写为“仅在对话中输出”或回退到其他默认路径。
- 导出成功后，最终回复中必须给出实际写入的文件路径。

## 分类体系

| 分类标签 | 适用场景 | 示例 |
|----------|----------|------|
| 国内要闻 | 中央政策、领导调研、外交活动、重大工程 | 习近平讲话、李强调研、普京访华 |
| 国际动态 | 国际冲突、跨国事件、外交谈判、地区局势 | 俄乌冲突、中东局势、美伊谈判 |
| 财经证券 | 金融市场、投资理财、股市债市、宏观经济政策 | 离境退税政策、上交所调研、股市动态 |
| 科技体育 | 科技突破、体育赛事、AI进展 | AI预测、世界杯、科技发布 |
| 社会民生 | 民生政策、社会事件、教育医疗、文化活动 | 全国助残日、食品安全、文化活动 |
| 行业观察 | 产业发展趋势、行业报告、企业动态、新技术应用 | 新能源车销量、芯片行业动态、AI赋能制造业 |

**分类边界说明**：
- **财经证券**侧重金融市场操作层面（炒股、投资、理财）
- **行业观察**侧重产业发展层面（趋势、报告、企业动态、新技术）
- **社会民生**侧重与民众日常生活直接相关的政策、事件和服务（政策落地、社会事件、服务措施）
- **行业观察**侧重某一行业或产业领域的发展趋势、企业动态和技术应用（产业发展、商业变化）

**社会民生 vs 行业观察 区分规则**：
| 维度 | 社会民生 | 行业观察 |
|------|----------|----------|
| 主体 | 普通民众、消费者、患者、学生等个体 | 企业、行业从业者、投资者、分析师 |
| 内容 | 政策对个人的影响、社会事件、服务体验 | 产业趋势、企业经营、技术革新 |
| 关键词 | 助残、就业、医疗、教育、养老、社区、文化活动 | 销量、产能、技术突破、并购、财报、新能源、半导体 |
| 举例 | "全国助残日活动启动" → 社会民生 | "新能源汽车Q1销量增长20%" → 行业观察 |
| 双重归属时 | 政策解读类 → 社会民生；产业分析类 → 行业观察 | 同上 |

**判断优先级**：标题关键词匹配 > 正文核心语义 > 来源媒体类型；仍无法区分时，按分类表顺序从上到下归类。

## 输出格式

### 完整输出模板
```markdown
# 主题新闻简报

> **检索时间范围**：YYYY-MM-DD 至 YYYY-MM-DD
> **主题关键词**：XXX
> **结果数量**：N条

---

## 内容分类

- **分类名称1**：X条
- **分类名称2**：X条

---

## 分类名称1

### 1. 新闻标题1
- **来源: XXX**
- **发布时间**：YYYY-MM-DD HH:MM
- **摘要**：...
- **正文**：...
- **链接**：https://...

### 2. 新闻标题2
...

## 分类名称2

### 3. 新闻标题3
...
```

### 单条新闻格式（6字段）
```markdown
### 序号. 新闻标题
- **来源: XXX**：【来源: XXX】格式标注
- **发布时间**：YYYY-MM-DD HH:MM
- **摘要**：1-2句话提炼核心事实
- **正文**：完整叙述，建议100-500字，叙述客观
- **链接**：https://...（有效URL）
- **置信度**（可选）：✅ 已验证 / ⚠️ 单源 / ❓ 待核实
```

### 输出规则
- 开头包含分类统计
- 使用 `## 二级标题` 作为分类标记
- 使用 `### 序号.` 作为新闻标题标记，序号在整篇输出中连续编号；同一分类内呈现为该分类的连续片段
- 分类按新闻数量降序排列
- 同分类内按发布时间降序，同时间按来源字母序

### 字段关系
- **摘要**：回答"是什么"，简短精炼
- **正文**：回答"详细是什么"，是摘要的延伸，不可与摘要重复

### 导出功能（可选）
- **Markdown导出**：用户说"导出为 Markdown"时

## 质量标准

| 指标 | 标准 |
|------|------|
| 返回数量 | 默认目标 5-10 条/次；用户可指定 1-20 条 |
| 内容相关性 | 标题必须含主题关键词 |
| 时效性 | 仅收录指定时间范围内的新闻 |
| 客观性 | 正文叙述客观，避免主观评价 |
| 链接有效性 | 必须可访问的真实URL |

**返回数量说明**：
- 未指定时，按相关性排序取前 10 条；过滤和去重后不足 10 条则保留全部，因此常见返回区间为 5-10 条。
- 用户指定返回数量时，按用户要求执行；超过 10 条时，自动启用并行搜索。

## 异常处理

| 情况 | 处理方式 |
|------|----------|
| 结果不足5条 | 直接返回，注明"找到 N 条结果" |
| 结果超过目标数量 | 按相关性保留到目标数量；用户未指定目标数量时保留前10条 |
| 无结果 | 当前时间范围小于30天时扩大到最多30天重试一次；仍无则返回"未找到..." |
| 工具返回格式异常 | 跳过该条；单次搜索任务累计异常条目>3条时终止搜索 |
| 时间解析失败 | 默认使用"近期"（30天） |
| 搜索工具限流(429) | 切换到其他可用 WebSearch 工具；全部限流等待30秒重试；仍失败告知用户 |
| 网络超时/失败 | 切换到其他可用 WebSearch 工具；全部失败告知用户"网络连接异常" |
| 内容安全拦截 | 跳过该条；单次搜索任务累计>5条拦截时终止搜索 |
| 搜索服务未授权或不可用 | 告知用户"当前环境没有可用的搜索服务" |
| 用户指定导出目录但未按该目录写入 | 视为执行失败；停止并重新按用户指定目录写入，不得回退到默认路径 |
| 用户指定路径不存在且当前环境不可创建 | 告知用户路径不可写或目录不存在，不得回退到默认路径 |
| 用户指定路径与导出格式扩展名冲突 | 保留用户指定文件路径，按该路径写入，并在回复中说明实际格式与文件扩展名不一致的风险；若用户只给目录，则按导出格式生成扩展名 |

## 工具使用

### 降级顺序
1. 当前首选 WebSearch 工具
2. 其他可用 WebSearch 工具
3. 全部失败 → "当前搜索服务暂时不可用"

### 并行搜索
**适用场景**：命中“工具选择原则”中的前四条并行规则，且当前环境中至少有两个可用 WebSearch 工具时

**执行方式**：同时调用多个可用 WebSearch 工具，取结果并集，来源标记为对应工具名或来源名，例如 `[来源: tool_a]`、`[来源: Reuters]`

### 工具失败回退
- 若首选工具不可用，切换到其他可用工具并保持相同 query 结构。
- 若所有可用工具都失败，明确告知用户失败原因，不输出伪结果。
- 若工具返回字段不完整，优先保留字段更完整的结果；缺失标题、来源、发布时间、摘要、正文、链接六字段中的任一字段时，不纳入最终输出。

## 来源偏好（可选）

用户可指定优先来源，如"优先使用新华社的消息"。相同内容按以下顺序保留：用户指定来源 > 权威性参考顺序更高的来源 > 发布时间更新的来源；不可用时自动回退。

**权威性参考**：新华社 > 人民日报 > 央视新闻 > 省级主流媒体 > 商业媒体

## 检索历史（会话级）

- 记录本次会话的主题关键词和时间范围，最多保留 10 条；超过 10 条时按先进先出移除最早记录
- 用户可引用："继续搜索上面的主题"、"用上次的时间范围搜索XX"
- 用户明确说"清除搜索历史"时清空
