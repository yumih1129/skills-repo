# 固定封面图规范

本技能的封面图不是自由创作，而是 `assets/cover-layout-reference.png` 约束下的模型生成结果。

## 唯一参考

- 唯一版式参考：`assets/cover-layout-reference.png`
- 唯一版式锚点：`assets/cover-layout-reference.png`
- 生成时必须把该图作为参考图输入模型
- 允许替换主题内容，不允许替换整体构图
- 文字提示只允许补强，不允许替代参考图约束

## 构图要求

封面必须与参考图同构，固定保留：

1. 左侧大标题区
2. 顶部深色识别条
3. 右侧 `5-6` 张热点卡片区
4. 至少 `1` 张深色锚点卡片
5. 暖米白底 + 棕褐 / 浅金主色

具体要求：

- 左侧必须突出日期或时间范围
- 左侧必须突出“热点新闻速览 / 今日速览 / 今日要闻”级别的大标题
- 日期只作时间锚点，字号较“热点新闻速览”类主标题缩小约 `10%`，不得与主标题争抢主视觉
- 左侧标题区应在参考图安全区内略向左收，和顶部识别条、导语区形成稳定左对齐
- 标题必须落在中心安全区，不得被裁切
- 右侧卡片必须是固定矩阵家族，不得改成散点排版或自由流式排版
- 右侧卡片尺寸与排序可在参考图版式家族内自适应，不得机械写死为等宽等高 `3x2`
- 卡片内容必须对应正文中的重点新闻主题
- 卡片允许替换为线稿、编辑部插画、信息图或抽象场景，但整体气质必须贴近参考图
- 核心规则：`封面必须以参考图为唯一版式锚点，模型只允许替换主题内容，不允许替换整体构图。`

## 视觉要求

- 暖米白、奶油白、浅金、棕褐为主色
- 保持编辑部专题感，不得变成纯营销海报
- 允许信息图、城市线稿、产业插画、国际议题场景
- 允许 `1` 张深色卡片作为视觉锚点

禁止项：

- 冷色霓虹
- 重照片拼贴
- 纯黑金奢华海报
- 大量 Logo、二维码、水印
- 密集小字、难以识别的长段文案

## 文案要求

封面上只允许出现：

- 日期或时间范围
- 主标题
- `5-6` 条卡片短标题或短副标题

封面文字必须：

- 与 `source.md` 主题一致
- 简短、可读、少错字
- 不堆长句
- 日期层级低于主标题，不得做成等强双标题；与主标题字号差控制在约 `10%`

## 生成要求

- 主链路固定为模型生成
- 提示词必须同时包含 `title`、`summary`、`cover_prompt` 和热点卡片要点
- 提示词可以强化日期、主标题、卡片短标题、色彩与信息密度，但不得把“仅靠文字描述排版”当作替代方案
- 首轮结果若出现错字、信息缺失或明显换版，可最多重试 `2` 次
- 不得把 `qlmanage`、Chromium 截图、SVG 栅格化或其他宿主特定链路声明为主生成方式

## 验收要求

以下条件必须同时满足：

- 能一眼看出与 `assets/cover-layout-reference.png` 属于同一版式家族
- 左侧大标题区仍是主视觉中心
- 左侧标题区与顶部识别条、导语区保持稳定左对齐
- 右侧仍是 `5-6` 张热点卡片矩阵，且属于固定矩阵家族而非自由流式排布
- 色彩仍是暖米白、棕褐、浅金体系
- 至少 `1` 张深色锚点卡片保留
- 主题内容已替换为本次新闻主题

## 不可漂移项

- 参考图路径不可改成技能外路径
- 输出文件名固定为 `scover.png`
- 封面主链路固定为模型生成
- 封面版式固定参考 `assets/cover-layout-reference.png`
- 文字提示不得上升为独立版式来源
