# 固定 HTML 版式规范

本文件定义本技能唯一允许的 HTML 风格。

## 目标气质

- 理性、克制、编辑部专题感。
- 暖白底，高信息密度，但层级清楚、留白稳定。
- 更像日报 / 热点简报 / 观察型专题，不像科技霓虹、纯黑极简、营销海报或门户快讯。

## 色彩与字体

- 页面底色：`#ffffff`
- 主文字色：`#2f241f`
- 次文字色：`#4f4139`、`#8a7b70`
- 强调色：`#a26d49`
- 分隔线 / 边框：`#dcc8b5`、`#e2d4c6`
- 浅底提示块：`#fcf8f4`、`#fbf6f1`、`#fdfaf6`

字体方向：

- 英文与数字优先衬线气质，中文优先系统无衬线兜底。
- 推荐栈：`'Times New Roman','PingFang SC','Hiragino Sans GB','Microsoft YaHei','Helvetica Neue',Arial,sans-serif`

## 页面骨架

固定顺序：

1. 正文首行 `# 标题` 渲染为 `h1`
2. 紧随其后的摘要段渲染为导语
3. 首个 `>` 引用块渲染为结论块
4. 若干 `h2` 主章节
5. 需要时穿插 `h3`、列表、表格、引用块
6. 末尾固定保留“原始报道链接 / 原始报道索引”章节
7. 结尾保留一段收束总结

## 容器与排版

- 页面最大宽度约 `680px`
- 左右内边距稳定，移动端优先
- 正文基础字号约 `15px`
- 正文行高约 `1.9`
- 标题左对齐
- 正文默认两端或接近两端对齐，不得出现极端字距拉伸

## 标题体系

### 眉题

- 不依赖眉题输入，不得从 frontmatter 或额外字段补出。

### `h1`

- 字号约 `26px`
- 字重 `700`
- 使用主文字色
- 不加渐变、阴影、描边
- 内容只允许来自正文首个 `#` 标题

### `h2`

- 字号约 `21px`
- 下方固定浅棕分隔线
- 章节间距明显大于段落间距

### `h3`

- 左侧细竖线强调
- 字号约 `15px`
- 不得改成按钮块、深底色条或彩色气泡

## 组件规范

### 结论块

- 米白底
- 四周细边框
- 左侧较粗强调线
- 圆角明显但克制
- 块内先放小标题，再放核心判断

### 列表

- 缩进稳定，单条行高与正文一致。
- 不得用表情符号或彩色 icon 充当项目符号。

### 表格

- 表头使用更浅暖色底，上下边界清楚。
- 不用深色底或高对比斑马纹。

### 引用块

- 只允许暖色浅底引用，左侧强调线比正文分隔线更明显。
- 不得渲染成社交媒体卡片风格。

### 链接索引

- 固定为末尾章节
- 使用列表逐条列出
- 保留来源名与 URL

## 禁止项

- 黑底荧光色、赛博色、渐变字、发光阴影
- 卡片瀑布流、三栏门户布局、仪表盘式排版
- 把每条新闻都渲染成独立营销卡片
- 使用脚本、外链样式表、图片背景正文
- 让 frontmatter 元数据直接进入 HTML

## 不可漂移项

- 暖白 + 棕褐体系不可改
- `h2` 下分隔线不可去掉
- `h3` 左侧细线强调不可改成其他组件
- 结论块必须存在，且位于正文前部
- 原始报道链接章节必须存在
- `h1` 与导语必须来自正文，而不是 frontmatter
